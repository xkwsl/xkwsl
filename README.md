# 每日打卡 · 手机版

一个**不用安装、不用上架、不用登录**的个人打卡工具。整个应用就是几个静态文件，数据只存在你自己手机的浏览器里，不联网、不上传、没有账号。

功能：每日打卡 / 记录消费金额 / 自定义项目（喝水、跑步、读书……）/ 月历热力图 / 近 30 天趋势 / 连续天数 / 本月合计与日均 / 补记过去的日子 / 导出导入备份。

---

## 装到手机（两种方式）

### 方式 A：免费托管（推荐，能离线用）

1. 打开 <https://app.netlify.com/drop>
2. 把**整个文件夹**（`index.html`、`manifest.webmanifest`、`icon.svg`、`sw.js`）拖进去
3. 等十几秒，拿到一个 `https://xxx.netlify.app` 链接
4. 手机浏览器打开这个链接：
   - **iPhone**：Safari → 底部「分享」→「添加到主屏幕」
   - **Android**：Chrome → 右上角「⋮」→「添加到主屏幕」
5. 之后从主屏图标打开，全屏运行，没网也能用

> 也可以换成 Cloudflare Pages、GitHub Pages、Vercel，玩法一样：传静态文件，得到 https 链接。
> 换设备或换浏览器时，只要打开同一个网址就行（数据不会跟着走，见下面「备份」）。

### 方式 B：直接打开文件（最快，适合先用用看）

把文件夹拷到手机（微信文件传输助手、iCloud、网盘都行），用浏览器打开 `index.html`。

能用，但**不建议长期这样用**：从「文件」里打开得到的是 `file://` 地址，添加不到主屏、数据也可能随系统清理丢失。只是先试用的话完全没问题。

## 每天怎么用

| 页面 | 能做什么 |
|---|---|
| 今日 | 打卡型点一下就是完成；数值型直接输数字，`+10 / +20 / +50 / 清零` 是快捷按钮 |
| 今日（左右箭头） | 补记前几天，右箭头到「今天」为止，记录不了未来 |
| 统计 | 顶部切换项目：日历热力、近 30 天柱状/点阵、合计与日均、当前连续与历史最长连续、最近记录 |
| 设置 | 增删改项目（名字、图标、类型、单位）、导出/导入备份、清空数据 |

点日历里任意一格可以跳到那一天补记。

**两种项目类型的区别**

- **打卡型**：只记「做没做」，比如背单词、跑步、早睡
- **数值型**：记具体数字，比如消费、步数、喝了几杯水

消费建议用数值型，单位填「元」。

## 数据与备份（重要）

- 所有记录存在**这台手机的这个浏览器**里（`localStorage`），没有服务器，也没有同步
- **换手机、清理浏览器数据、卸载浏览器之前**：设置 → 导出备份（JSON），换好之后再导入
- iOS 对长期不访问的站点可能清理本地存储；你每天都打开的话不会触发
- 导出的 JSON 是纯文本，可以自己存到网盘

## 文件说明

```
index.html            主程序，HTML + CSS + JS 全在这一个文件里
manifest.webmanifest  主屏图标、全屏模式等配置
icon.svg              图标（矢量）
icon-180.png          主屏图标（iOS 用）
icon-192.png          主屏图标（Android 用）
icon-512.png          主屏图标（高清 / 应用商店用）
sw.js                 离线缓存（网络优先，断网时用缓存）
```
